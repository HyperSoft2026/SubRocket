# SubRocket 🚀

بوت تيليجرام باللهجة العراقية لنظام نقاط وتمويل القنوات العامة. المستخدمون ينضمون باختيارهم للقنوات المشاركة، وبعد التحقق من عضويتهم يحصلون على نقاط، ويمكن لأصحاب القنوات استخدام النقاط لتمويل حملاتهم.

## الإصدار
`0.0.0` — إصدار تأسيسي تجريبي.

## متغيرات البيئة على Clever Cloud

| المتغير | الاستخدام |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_BOT_USERNAME` | اسم البوت بدون @ (محفوظ لإعدادات الربط المستقبلية) |
| `TELEGRAM_ADMIN_ID` | أيدي المدير الرقمي |
| `POSTGRESQL_ADDON_URI` | رابط PostgreSQL من Clever Cloud |
| `POINTS_PER_MEMBER` | نقاط المكافأة لكل اشتراك مؤكد؛ الافتراضي 100 |

يحقن Clever Cloud المتغير `PORT` تلقائياً. البوت يعمل حالياً عبر Telegram long polling ولا يحتاج Webhook أو منفذ HTTP.

## الأوامر

- `/start` — تسجيل المستخدم وعرض القائمة.
- `/points` — عرض الرصيد.
- `/campaigns` — عرض الحملات المتاحة.
- `/promote @channel 10` — إنشاء حملة لعشرة أعضاء.
- `/help` — التعليمات.
- `/admin` — إحصائيات المدير.

## طريقة إنشاء حملة

1. صاحب القناة يضيف البوت مشرفاً إلى قناته العامة.
2. ينفذ `/promote @channel 10`.
3. يحجز النظام تكلفة الحملة من رصيد النقاط.
4. المستخدم ينضم للقناة باختياره ثم يضغط «تحقق واستلم».
5. يتحقق البوت من العضوية عبر Telegram Bot API، ثم يمنح النقاط مرة واحدة لكل مستخدم ولكل حملة.

## ملاحظات مهمة

- يجب أن يكون البوت مشرفاً في القناة حتى يستطيع التحقق من عضوية المستخدمين.
- لا توجد نقاط مجانية تلقائية في هذا الإصدار؛ رصيد البداية صفر، ويُكتسب من الحملات.
- هذا إصدار تجريبي أولي وليس نظاماً تجارياً مكتملاً. لا توجد بعد لوحة إدارة رسومية أو استردادات تلقائية للحملات غير المكتملة.
- لا تضع التوكن أو بيانات قاعدة البيانات في ملفات المستودع.
- يشجع SubRocket الاشتراك الحقيقي والاختياري فقط، ولا يدعم الحسابات الوهمية أو الانضمام الآلي.
