# SubRocket 🚀

بوت تيليجرام لإدارة النقاط وحملات دعم القنوات العامة، مع لوحة تحكم تفاعلية داخل تيليجرام.

## الإصدار
`0.0.1` — لوحة إدارة داخل البوت وإدارة النقاط والإعدادات والحملات.

## متغيرات البيئة على Clever Cloud

| المتغير | الاستخدام |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_BOT_USERNAME` | اسم البوت بدون @ (اختياري حالياً) |
| `TELEGRAM_ADMIN_ID` | أيدي المدير الرقمي؛ وحده يستطيع فتح لوحة الإدارة وتنفيذ إجراءاتها |
| `POSTGRESQL_ADDON_URI` | رابط PostgreSQL من Clever Cloud |
| `POINTS_PER_MEMBER` | القيمة الافتراضية لتكلفة/مكافأة العضو عند أول تهيئة؛ الافتراضي 100 |

لا تضع التوكن أو بيانات قاعدة البيانات داخل ملفات المستودع. البوت يعمل عبر Telegram long polling ولا يحتاج Webhook.

## لوحة الإدارة

اكتب `/admin` من حساب المدير المحدد في `TELEGRAM_ADMIN_ID`. لوحة الإدارة تتضمن:

- إحصائيات المستخدمين والأرصدة والحملات والاشتراكات المتحققة.
- إضافة نقاط أو خصمها من مستخدم، أو الاستعلام عن رصيده.
- استعراض آخر المستخدمين المسجلين.
- إرسال رسالة نصية لجميع المستخدمين غير المحظورين.
- استعراض الحملات وإلغاء حملة نشطة وإرجاع قيمة الخانات المتبقية إلى صاحبها.
- تغيير تكلفة العضو وتشغيل/إيقاف وضع الصيانة.

كل إجراءات الإدارة محمية بفحص أيدي المدير في الخادم، وليس بمجرد إخفاء الأزرار. أوامر الإدارة والرسائل النصية الإدارية لا تستجيب لحسابات المستخدمين العاديين.

## أوامر المستخدم

- `/start` — التسجيل والقائمة الرئيسية.
- `/points` — الرصيد الحالي.
- `/campaigns` — الحملات المتاحة.
- `/promote @channel 10` — إنشاء حملة لعشرة أعضاء.
- `/help` — المساعدة.

## التحقق والرصيد

1. يضيف صاحب القناة البوت مشرفاً إلى القناة العامة.
2. ينشئ حملة بعد توفر رصيد كافٍ.
3. ينضم المستخدم للقناة باختياره ثم يضغط «تحقق واستلم».
4. يتحقق البوت من عضوية المستخدم عبر Telegram Bot API ويمنح المكافأة مرة واحدة لكل مستخدم وحملة.
5. عند إلغاء المدير حملة نشطة، يعاد لصاحبها رصيد الخانات غير المستخدمة وفق مكافأة العضو المسجلة بالحملة.

## التحديث من 0.0.0 إلى 0.0.1

تُضاف جداول الإعدادات وحالة الحظر تلقائياً مع الحفاظ على جداول المستخدمين والحملات وسجل النقاط الموجود. إعداد تكلفة العضو يُخزّن في PostgreSQL، لذلك لا يتغير عند إعادة تشغيل التطبيق بعد ضبطه من لوحة الإدارة.

## ملاحظات

- يجب أن يكون البوت مشرفاً بالقناة حتى يستطيع التحقق من عضوية المستخدمين.
- الاشتراك يجب أن يكون حقيقياً واختيارياً؛ لا يدعم المشروع الحسابات الوهمية أو الانضمام الآلي.
- الإذاعة ترسل الرسالة بالتتابع إلى المستخدمين المسجلين غير المحظورين؛ قد يفرض Telegram حدوداً على سرعة الإرسال.
- لا توجد حالياً واجهة ويب؛ التحكم الإداري يتم من محادثة البوت.
