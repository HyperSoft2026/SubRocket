# SubRocket 🚀

منصة Telegram لإدارة حملات الاشتراك والتسويق المجتمعي والمكافآت.

## الإصدار
`0.0.4` — Evolution Update. يتضمن هذا الفرع أساس المنصة الجديد: ترحيلات مرقمة، سجل مالي يدعم منع تكرار العمليات، صندوق أحداث Outbox، سجل تغييرات الحملات، قنوات أصحاب الحملات، السمعة، المهام، المفضلة، حالات التحقق من الاحتفاظ بالعضوية، وصلاحيات موظفين محددة.

## التوافق وحماية البيانات
- يحافظ على جداول وبيانات 0.0.2 و0.0.3؛ لا توجد أوامر حذف أو إعادة إنشاء للجداول القديمة.
- يضيف `schema_migrations` ويسجل الترحيل رقم 4 داخل معاملة PostgreSQL واحدة.
- المطالبات القديمة تُصنّف `verified` و`reward_paid=true` للحفاظ على تاريخها، ولا يعاد صرف مكافآتها.
- لا يُفعّل التحقق المؤجل تلقائياً؛ `retention_verification_enabled=false` افتراضياً حتى يتم تفعيل دورة التحقق واختبارها على قناة حقيقية.
- سجل النقاط القديم محفوظ كما هو. يدعم العمود `idempotency_key` مفاتيح فريدة للعمليات الجديدة التي تستخدم خدمة `applyLedgerEntry`.

## أساس v0.0.4
- `platform-v4.js`: ترحيل المنصة، RBAC، دفتر النقاط بمنع التكرار، Outbox، سجل الحملات والنشاط.
- `campaign-engine.js`: إنشاء الحملات وتمويلها وإلغاؤها وإرجاع الرصيد وإدارة حالات الإيقاف والاستئناف ومراجعة الإدارة.
- `platform-workers.js`: التحقق المؤجل من العضوية، إنهاء الحملات المنتهية، ومعالجة إشعارات Outbox مع إعادة المحاولة.
- `reward-center.js`: مكافأة تسجيل الدخول اليومية وسلسلة الاستمرارية وتحليلات المستخدم.
- جداول قنوات المالكين، السمعة، المهام، تقدم المستخدمين، مكافآت الدخول اليومية، المفضلة، الإشراف، صحة الخدمات.
- حقول وصف الحملة والصورة والتصنيف والانتهاء والمراجعة.
- حالات المطالبة: pending / verified / rejected.
- أدوار الموظفين: admin / moderator / support / analyst. لوحة الفريق تعرض أدوات بحسب الدور؛ المدير الرئيسي المحدد في `TELEGRAM_ADMIN_ID` وحده يستطيع منح الأدوار.
- اختبارات Node المبدئية: `npm test`.

## متغيرات البيئة
| المتغير | الاستخدام |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `TELEGRAM_ADMIN_ID` | أيدي المدير الرئيسي |
| `POSTGRESQL_ADDON_URI` أو `DATABASE_URL` | اتصال PostgreSQL |
| `POINTS_PER_MEMBER` | تكلفة تمويل المقعد الافتراضية عند التهيئة الأولى |

لا تحفظ الأسرار داخل المستودع. يعمل البوت عبر Telegram long polling.

## حدود التنفيذ الحالية
هذا الفرع يربط واجهات القنوات المحفوظة، تفاصيل الحملات والمفضلة، إحصائيات صاحب القناة، إيقاف/استئناف الحملات، مراجعة الحملات، مكافأة الدخول اليومية، تحليلات المستخدم، أدوار الفريق الأساسية، والتحقق المؤجل الاختياري. ما زالت واجهات تحرير تفاصيل الحملة وتجديدها وتمديدها، المهام اليومية/الأسبوعية والشهرية، التحديات الموسمية، التصدير CSV، الإذاعة المجدولة، الشكاوى/الاعتراضات، وتحليلات الإدارة المتقدمة بحاجة إلى استكمال.

التحقق المؤجل معطل افتراضياً، ويمكن للمدير تفعيله من إعدادات البوت وتحديد 6–168 ساعة. لا تفعّله في الإنتاج قبل التأكد من أن البوت مشرف بالقنوات المقصودة. اختبارات CI الأساسية نجحت على فرع التطوير، لكن لم يتم بعد اختبار الترحيل على نسخة من قاعدة بيانات الإنتاج أو اختبار Telegram/Clever Cloud الحي.
