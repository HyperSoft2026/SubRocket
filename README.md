# SubRocket 🚀

بوت تيليجرام لإدارة النقاط وحملات القنوات العامة، مع واجهة تعتمد على الأزرار ولوحة تحكم خاصة بالمدير.

## الإصدار
`0.0.2` — تجربة استخدام بالأزرار، أوامر مخصصة حسب الحساب، وإنشاء الحملات من داخل الواجهة.

## أوامر تيليجرام

- المستخدمون: `/start` و`/help` فقط.
- المدير المحدد في `TELEGRAM_ADMIN_ID`: `/start` و`/help` و`/adminadmin`.
- أمر `/adminadmin` غير مدرج في قائمة أوامر المستخدمين. إذا أرسله مستخدم غير المدير يظل البوت صامتاً تماماً.
- لا توجد أوامر نصية للمستخدمين لعرض الرصيد أو الحملات أو إنشاء حملة؛ هذه العمليات تتم من الأزرار.

## متغيرات البيئة على Clever Cloud

| المتغير | الاستخدام |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather |
| `TELEGRAM_BOT_USERNAME` | اسم البوت بدون @ (اختياري) |
| `TELEGRAM_ADMIN_ID` | أيدي المدير الرقمي |
| `POSTGRESQL_ADDON_URI` | رابط PostgreSQL |
| `POINTS_PER_MEMBER` | تكلفة/مكافأة العضو الافتراضية عند التهيئة الأولى؛ الافتراضي 100 |

لا تضع الأسرار داخل المستودع. يعمل البوت عبر Telegram long polling.

## واجهة المستخدم

- ⭐ رصيدي: عرض الرصيد عبر زر.
- 🚀 الحملات المتاحة: استعراض القنوات والانضمام الاختياري ثم التحقق.
- ➕ إنشاء حملة: معالج تفاعلي يطلب معرف القناة وعدد المقاعد، ويتحقق من صلاحيات البوت والرصيد قبل الخصم.
- ℹ️ المساعدة: شرح مختصر داخل الواجهة.

## لوحة المدير

يفتحها المدير فقط بالأمر `/adminadmin`. قائمة الأوامر الافتراضية للمستخدمين لا تعرض هذا الأمر، ويُضاف إلى قائمة الأوامر الخاصة بمحادثة المدير فقط.

تتضمن اللوحة الإحصائيات، إدارة النقاط، البحث عن المستخدمين وحظرهم، الإذاعة، إدارة الحملات وإلغاءها مع إعادة الرصيد غير المستخدم، وتغيير تكلفة العضو ووضع الصيانة. يتم فحص هوية المدير في كل callback إداري على الخادم.

## التحقق والرصيد

1. يضيف صاحب القناة البوت مشرفاً بالقناة العامة.
2. ينشئ الحملة من الأزرار بعد إدخال معرف القناة وعدد المقاعد.
3. ينضم المستخدم للقناة باختياره ثم يضغط «تحقق واستلم».
4. يتحقق البوت من العضوية عبر Telegram Bot API ويمنح المكافأة مرة واحدة لكل مستخدم وحملة.
5. إلغاء حملة نشطة من لوحة المدير يعيد قيمة المقاعد غير المستخدمة إلى صاحبها.

## قاعدة البيانات

تُنشأ الجداول والفهارس تلقائياً مع الحفاظ على بيانات المستخدمين والحملات وسجل النقاط الموجود. إعدادات البوت تُحفظ في PostgreSQL.

## ملاحظات

- الاشتراكات حقيقية واختيارية؛ لا توجد حسابات وهمية أو آلية انضمام تلقائي.
- Telegram يفرض حدوداً على سرعة الإذاعة.
- لم يتم بعد إجراء اختبار حي كامل لكل الأزرار على حساب Telegram؛ يلزم التحقق بعد إعادة تشغيل Clever Cloud.
