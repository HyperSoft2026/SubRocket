# SubRocket 🚀

منصة تيليجرام لإدارة حملات الاشتراك بالقنوات العامة، ونظام نقاط ومكافآت وإحالات.

## الإصدار
`0.0.3` — توسعة قاعدة البيانات وتجربة المستخدم بإضافة المحفظة، المتصدرين، المستويات، الإحالات، القسائم، الإشعارات وتذاكر الدعم، مع الإبقاء على بيانات الإصدار السابق.

## أوامر تيليجرام
- المستخدمون: `/start` و`/help` فقط.
- المدير الرئيسي المحدد في `TELEGRAM_ADMIN_ID`: `/start` و`/help` و`/adminadmin`.
- أمر `/adminadmin` لا يظهر في قائمة المستخدمين، وأي مستخدم غير المدير يرسله لا يتلقى رداً.
- جميع خدمات المستخدمين متاحة عبر الأزرار.

## متغيرات البيئة
| المتغير | الاستخدام |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `TELEGRAM_BOT_USERNAME` | اسم البوت (اختياري) |
| `TELEGRAM_ADMIN_ID` | أيدي المدير الرئيسي |
| `POSTGRESQL_ADDON_URI` أو `DATABASE_URL` | اتصال PostgreSQL |
| `POINTS_PER_MEMBER` | تكلفة تمويل المقعد الافتراضية عند التهيئة الأولى |

لا تحفظ الأسرار داخل المستودع. يعمل البوت عبر Telegram long polling.

## واجهة المستخدم
- المحفظة: الرصيد، المكتسب، المصروف وآخر المعاملات.
- المتصدرون: ترتيب عام وأسبوعي وشهري.
- الإنجازات: مستويات مبتدئ ونشيط ومحترف وأسطوري وشارات حسب نشاط الحملات.
- الإحالات: رابط دعوة خاص، وتُمنح المكافأة بعد أول مطالبة اشتراك حقيقية متحققة للمدعو.
- القسائم: استرداد كود مرة واحدة لكل مستخدم.
- الإشعارات: مركز إشعارات داخل البوت.
- الدعم الفني: إرسال تذكرة من الأزرار.
- الحملات الحالية: إنشاء حملة والتحقق من عضوية القناة عبر Telegram Bot API.

## إدارة القسائم
من لوحة المدير يظهر زر إنشاء كود مكافأة. الصيغة:
`CODE POINTS MAX_USES`
مثال: `ROCKET100 100 50`

## قاعدة البيانات والتوافق
يضيف الإصدار جداول وفهارس جديدة وأعمدة للحملات باستخدام `CREATE TABLE IF NOT EXISTS` و`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`. لا يحذف جداول أو سجلات الإصدار السابق. تبقى جداول المستخدمين والحملات والمطالبات وسجل النقاط كما هي.

الجداول الإضافية: `referrals`, `notifications`, `reward_coupons`, `coupon_redemptions`, `user_achievements`, `admin_audit_log`, `support_tickets`.

## الحماية وحدود الإصدار
- المطالبة بالحملة محمية بقفل صف PostgreSQL وقيد فريد لكل مستخدم/حملة.
- استرداد القسيمة محمي بمعاملة وقيد فريد لكل مستخدم/قسيمة.
- مكافأة الإحالة تُصرف مرة واحدة بعد أول اشتراك متحقق للمدعو.
- سجل النقاط السابق لا يُحذف.
- الإحالات لا تثبت أن الحساب بشري أو فريد؛ لا يوجد حظر آلي اعتماداً على مؤشرات غير قطعية.
- لا يزال توسيع دورة حياة الحملات (التصنيفات، الإيقاف والاستئناف، انتهاء الصلاحية، استرداد المقاعد تلقائياً)، صلاحيات المشرفين، طوابير الإذاعة، تقارير التصدير، وردود الدعم من لوحة المدير بحاجة إلى استكمال واختبار.
- لم يتم تأكيد التشغيل الحي بعد هذا التحديث. أعد تشغيل التطبيق على Clever Cloud ثم راقب سجلات الإقلاع قبل اعتماد الإصدار.
