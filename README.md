# SubRocket
SubRocket 🚀 هو بوت تيليجرام يساعد أصحاب القنوات والكروبات على زيادة مجتمعهم بطريقة تفاعلية، من خلال نظام نقاط ومكافآت. المستخدم يجمع النقاط من تنفيذ المهام المتاحة، ويكدر يستبدلها بتمويل قناته أو كروبه بمشتركين حقيقيين. يتضمن البوت نظام حسابات ونقاط وطلبات تمويل ولوحة تحكم للإدارة، مع إمكانية متابعة العمليات وإدارة المهام والمكافآت بكل سهولة.
